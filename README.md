# Getting Started
Similar to the getting started of the main repo, you can just clone and compile with Visual Studio.
Feel free to run the game and try out the different menus.

Want to use the framework by itself? Get started on with the template repository [here](https://github.com/ImNotStealth/Stellar).

> [!NOTE]
> Feel free to re-use code but do note that the following assets have not been made by me but by teammates when making this game so I do not own them!\
> Please refrain from using the following assets:\
> `Assets/Sounds/Music/*`\
> `Assets/Sprites/*`\
> `Assets/UI/SelectCreateWorld/*`\
> `Assets/UI/Background.png`\
> `Assets/UI/Grass.png`
